# BATIEXPERTS 🏗️

Application web de gestion des clients et des commandes d'une entreprise du bâtiment.

## 📓 CONTEXTE

Projet réalisé en binôme pour appliquer l'architecture MVC en PHP, dans le cadre de la formation Développeur Web et Web Mobile à SIMPLON.CO, en avril 2025.

## 🎯 FONCTIONNALITÉS

- Gestion des clients : liste, fiche, création, modification
- Gestion des commandes : liste, fiche, création, modification
- Page d'erreur 404

## 🛠 TECHNOLOGIES

| Technologie | Usage |
|---|---|
| PHP | Back-end, architecture MVC avec repositories |
| MySQL | Base de données |
| HTML / CSS | Vues et mise en forme |

## 🚀 INSTALLATION

1. Cloner le projet

   ```bash
   git clone https://github.com/kays-dev/BatiExperts.git
   cd BatiExperts
   ```

2. Renseigner les accès à la base dans `lib/database.php`
3. Lancer un serveur local (MAMP, XAMPP ou `php -S localhost:8000`) et ouvrir `index.php`
